> 都在共享包：`tools/node_modules/dsh-pipeline/docs/CONTRACT.md`（源码仓 `~/workspace/dsh-pipeline`）。本文件只写**本仓**才有的东西。

## 入口

`scripts/pipeline/` 里**全是生成物**（`# GENERATED by dsh-pipeline`，禁止手改），转发到包内对应子命令（`new-task.sh`→`task`、`open-pr.sh`→`pr`、`merge-pr.sh`→`merge`，`review`/`status` 同名）；`scripts/pipeline/README.md` 是人工维护的目录说明。

| 入口 | 包子命令 | 说明 |
|---|---|---|
| `pipeline.sh <args…>` | 原样透传 | 需要包内其它子命令时用 |
| `new-task.sh <issue#>` | `task` | issue → worktree + 分支，幂等 |
| `open-pr.sh [-C <dir>]` | `pr` | 推送并开 PR；PR 已存在时只打印链接，**不 push**（后续提交自行 `git push`） |
| `review.sh prepare\|publish` | `review` | 生成审核请求 / 落盘判定 |
| `merge-pr.sh [<PR号>] [-C <dir>]` | `merge` | 闸门 → CI → squash 合并 → 清理现场 |
| `status.sh` | `status` | 只读状态（worktree / 分支 / 开放 PR） |

`tools/` 用 `link:` 指向 `~/workspace/dsh-pipeline/dist/pkg`（唯一解包产物）。改包后在包仓跑 `pnpm run pack`，`dist/pkg` 原子切换后即时生效。**必须用绝对路径**：相对路径在 worktree 下会错位（`tools/` 每个 worktree 各一份）。

## 本仓约定

- **仓库解析（issue #108）**：所有脚本的 `REPO_ROOT` 取**脚本自身位置**，与 cwd 无关；`open-pr.sh` / `merge-pr.sh` 支持 `-C <dir>` / `--worktree <dir>` 覆盖目标。失败信息会带「目标工作区 / 分支 / 调用 cwd」。
- **worktree / 分支**：`.worktrees/<N>-<slug>`、`task/<N>-<slug>`；从主仓根用绝对路径创建。
- **合并与清理**：squash 唯一、PR body 首行 `Closes #N`（见全局 `~/.dsh/AGENTS.md` §7.3）。`merge-pr.sh` 负责：移除 worktree → `fetch` → 主工作区 `merge --ff-only` → 删本地分支（`-D`）。它**不做 `worktree prune`**；**远端分支不由脚本删除**（`gh pr merge --squash` 不带 `--delete-branch`，是否删取决于仓库的 auto-delete 设置）。
- **门禁（在 `agent-mobile-app/` 内跑）**：
  ```bash
  ( cd agent-mobile-app && pnpm exec tsc --noEmit )
  ( cd agent-mobile-app && pnpm test )     # vitest，src/**/*.test.ts
  ( cd agent-mobile-app && pnpm lint )
  ```
  新 worktree 首次跑门禁前先 `( cd agent-mobile-app && pnpm install )`。
- **GitHub HTTPS 经常抖动**：origin 若为 HTTPS，push/fetch 显式走 SSH——`git push git@github.com:guraul/agent-mobile.git <branch>`（2026-11-06 起本仓 origin 已是 SSH）。
- **`deploy-web.yml` 只认 `agent-mobile-app/**` 与 workflow 自身**：合并流水线脚本、文档、知识库**不会触发部署**（homebase 不同，那边 `scripts/**` 在 paths 里）。
- **高风险 = 人工放行**：命中本仓 `.dsh/pipeline.json` 的 `highRisk` 或包默认策略（`.dsh/**`、`AGENTS.md`、`scripts/pipeline/**`、`docs/pipeline/**`、`**/package.json` 依赖变更、单次 >400 行等）时报 `E_POLICY`，需用户当场同意后用 `--no-review --reason=`；跳过审计脚本自动写，**PR 评论要自己发**。
